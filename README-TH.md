# Beat Studio Fantasy — ชุดอัปโหลดเว็บไซต์

ชุดนี้ใช้เวอร์ชันล่าสุด v1.7 รวมการอัดโน้ตจากคีย์บอร์ด/MIDI, Mixer ในแทร็ก, Master แนวตั้ง, Pan สแน็ป Center และตัวเลือกธีม Pixel สว่าง / Fantasy มืด

## อัปโหลด
1. แตกไฟล์ ZIP นี้
2. อัปโหลดเนื้อหาภายในโฟลเดอร์ Beat-Studio-Website ไปยังโฟลเดอร์เว็บไซต์ของโฮสติ้ง เช่น public_html หรือโฟลเดอร์เผยแพร่ที่ผู้ให้บริการกำหนด
3. ให้ index.html อยู่ที่หน้าแรกของเว็บไซต์ ไม่ซ้อนอยู่ในโฟลเดอร์ ZIP อีกชั้นโดยไม่ตั้งใจ
4. เปิดเว็บไซต์ผ่าน HTTPS แล้วตรวจการเล่นเสียง บันทึก/นำเข้าโปรเจกต์ และส่งออก WAV

ไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build ไม่ต้องใช้ฐานข้อมูล เซิร์ฟเวอร์แอป หรือ API key โฮสต์แบบ static ที่ให้บริการ HTML ได้ก็ใช้ได้ ตัวเว็บรวม CSS และ JavaScript ไว้ใน index.html ไม่มีไฟล์เสียงหรือฟอนต์ภายนอกที่ต้องโหลด

## ไฟล์ในชุด
- index.html: ตัวเว็บครบทั้งหมด (ไฟล์นี้ไฟล์เดียวก็ใช้งานได้)
- examples/: โปรเจกต์ JSON ตัวอย่าง ใช้ปุ่มนำเข้าในเว็บเพื่อเปิด
- docs/: คู่มือการแต่งเพลง คีย์บอร์ด/MIDI และการอัดโน้ต (คู่มือรุ่นก่อนอาจแสดงตำแหน่งเมนูเดิม)
- README-TH.md: วิธีอัปโหลดและข้อควรรู้

## ข้อมูลและการย้ายจากไฟล์ในเครื่อง
เพลงและธีมที่บันทึกอัตโนมัติอยู่ในเบราว์เซอร์ของแต่ละคน ไม่มีบัญชีผู้ใช้หรือการซิงก์ข้ามเครื่อง ข้อมูลจากไฟล์ในเครื่องจะไม่ย้ายไปยังโดเมนใหม่เอง ให้เปิดไฟล์เดิม กดส่งออกโปรเจกต์ JSON แล้วนำเข้าในเว็บจริง เก็บ JSON สำรองไว้ก่อนล้างข้อมูลเบราว์เซอร์หรือย้ายโดเมน

## USB MIDI
ให้บริการเว็บผ่าน HTTPS และอนุญาตการเข้าถึง MIDI ในเบราว์เซอร์ที่รองรับ หากนำเว็บไปฝังใน iframe อาจมีข้อจำกัดสิทธิ์จากเว็บไซต์แม่ แนะนำให้เปิดหน้าเว็บโดยตรงเพื่อตรวจการเชื่อมต่อ อุปกรณ์ USB MIDI จริงยังไม่ได้รับการทดสอบในขั้นตอนจัดแพ็กนี้

## ตรวจหลังอัปโหลด
- เปิดหน้าแรกและสลับธีมได้ รีเฟรชแล้วจำธีม
- เลือกเครื่องดนตรี วางโน้ต กด Play/Stop
- ปรับ Volume, Pan และ Master
- ทดลอง Step Input และอัดโน้ต
- ส่งออก JSON แล้วนำกลับเข้าได้ และดาวน์โหลด WAV ได้

นี่คือชุดไฟล์พร้อมอัปโหลด ยังไม่ได้เผยแพร่ไปยังโฮสติ้งจริง
