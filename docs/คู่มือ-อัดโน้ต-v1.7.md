# Beat Studio Fantasy v1.7

เปิด Beat-Studio-Fantasy-v1.7.html แล้วเลือกแทร็กเครื่องดนตรีที่ต้องการ

## วางจากแป้นทีละจังหวะ
1. ใน Live Keyboard เลือก “วางโน้ตทีละจังหวะ (Step Input)”
2. เลือกความยาวในส่วน Piano Roll และคลิกไม้บรรทัดเพื่อกำหนดจุดเริ่ม
3. กด Z X C หรือปุ่มอื่นตามตัวอักษรบนเปียโน โน้ตจะถูกเพิ่มทันที
4. กดหลายปุ่มค้างเพื่อวางคอร์ด เมื่อปล่อยทั้งหมด เส้นเล่นจะเลื่อนไปตามความยาวที่เลือก
5. “เว้นจังหวะ →” เลื่อนโดยไม่เพิ่มโน้ต เมื่อถึงท้ายเพลงจะวนกลับต้นเพลง

โหมดนี้ใช้เมื่อเพลงหยุด หากต้องการบันทึกระหว่างเพลงเล่น ให้กดอัดโน้ต

## อัดขณะเล่น
กด “● อัดโน้ต” เพื่อเริ่มเพลงจากตำแหน่งปัจจุบัน แล้วเล่นจากแป้นพิมพ์ ปุ่มเปียโนบนจอ หรือ USB MIDI กด “■ หยุดอัด” เพื่อจบ

โน้ตจะปรากฏเมื่อปล่อยปุ่ม เก็บความยาวและความแรง พร้อมจัดตำแหน่งและความยาวลงช่อง 1/16 อัดเพิ่มบนโน้ตเดิม ไม่มีการลบโน้ตเดิมโดยอัตโนมัติ โน้ตที่ข้ามท้ายเพลงแบ่งต่อที่ต้นเพลง และจำกัดความยาวไม่เกินหนึ่งรอบ

Sustain จาก MIDI จะยืดโน้ตจนปล่อยแป้นเหยียบ การเปลี่ยนแทร็กหรือหยุดเพลงจะจบการอัดด้วย Ctrl+Z หรือปุ่ม Undo ย้อนชุดที่อัดได้ ควรหยุดอัดก่อนแก้ไขโน้ตด้วยเครื่องมืออื่น

บันทึกและส่งออก JSON ได้ตามเดิม โน้ตที่เพิ่มใช้เล่นและส่งออก WAV ได้เหมือนโน้ตที่วางด้วยเมาส์

## การตรวจสอบ
ทดสอบหน้าเว็บด้วยแป้นพิมพ์จริงผ่านการควบคุมเบราว์เซอร์: วางโน้ต อัดโน้ต หยุด และ Undo ผ่าน ไม่พบข้อผิดพลาดในคอนโซล

ทดสอบตรรกะคอร์ด การเลื่อนตำแหน่ง โน้ตสั้น ความแรง การแบ่งโน้ตข้ามลูป และจบโน้ตที่ค้างเมื่อหยุด ผ่าน ทดสอบข้อความ MIDI จำลองและ Sustain ผ่าน ยังไม่ได้ทดสอบกับอุปกรณ์ USB MIDI จริง
