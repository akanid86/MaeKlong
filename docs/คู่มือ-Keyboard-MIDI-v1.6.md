# Beat Studio Fantasy v1.6 — Live Keyboard และ USB MIDI

เปิด **Beat-Studio-Fantasy-v1.6.html** แล้วเลือกแทร็กเครื่องดนตรีที่ต้องการเล่น ส่วน Live Keyboard ใช้เครื่องดนตรี, ระดับเสียง, Master, Pan และเอฟเฟกต์ของแทร็กนั้น กดฟังได้แม้แทร็กถูก Mute/Solo ในเพลง

## เล่นจากแป้นพิมพ์

1. เปิดช่อง **เล่นจากแป้นพิมพ์**
2. เลือกช่วงเสียงเริ่ม เช่น C3–C5 หรือ C4–C6
3. ใช้ปุ่มแถวล่าง `Z S X D C V G B H N J M` และแถวบน `Q 2 W 3 E R 5 T 6 Y 7 U I` ตามตัวอักษรบนคีย์เปียโน
4. กดค้างเพื่อถือเสียง ปล่อยเพื่อจบโน้ตตาม Release กดหลายปุ่มเพื่อเล่นคอร์ดได้ สูงสุด 32 เสียง เสียงสายดีดและโลหะยังค่อย ๆ ดับตามลักษณะ preset

ใช้ตำแหน่งปุ่มจริง จึงใช้ได้เมื่อเลือกภาษาไทย หากเคอร์เซอร์อยู่ในช่องข้อความ ตัวเลข หรือเมนู ให้คลิกชื่อ Live Keyboard ก่อนเล่น ปุ่มลัด Ctrl/Cmd+C/V/Z ยังใช้แก้โน้ตตามเดิม

คลิกหรือแตะคีย์บนหน้าจอได้ด้วย แทร็ก Drums / Frame Drums แสดง 8 แป้น: Kick, Snare, Hi-Hat, Open Hat, Clap, Tom, Crash, Ride ใช้ `Z X C V B N M Q`

เปลี่ยนแทร็กหรือช่วงเสียงจะหยุดเสียงที่ค้างอยู่ ปุ่ม **หยุดเสียงทั้งหมด** และ Stop ใช้หยุดเสียงสดได้ เมื่อออกจากหน้าต่าง/ซ่อนแท็บก็จะหยุดเสียงสดเพื่อป้องกันโน้ตค้าง

## เล่นจาก USB MIDI

1. เสียบคีย์บอร์ดหรือ MIDI controller เข้าคอมพิวเตอร์ให้ระบบปฏิบัติการรู้จักก่อน หากรุ่นนั้นต้องใช้ไดรเวอร์ ให้ใช้ของผู้ผลิต
2. เปิดเว็บในเบราว์เซอร์ที่รองรับ Web MIDI แล้วกด **เชื่อมต่อ USB MIDI** และอนุญาตคำขอของเบราว์เซอร์
3. เลือกอุปกรณ์และช่อง MIDI หรือใช้ทุกอุปกรณ์/ทุกช่อง
4. เลือกแทร็กใน Beat Studio แล้วเล่นจากอุปกรณ์

รองรับ Note On/Off, Note On ที่ velocity=0, ความแรงจากอุปกรณ์, Sustain CC64, All Sound Off CC120, Reset Controllers CC121 และ All Notes Off CC123 ตรวจการเสียบ/ถอดอุปกรณ์ และมีปุ่มตัดการเชื่อมต่อ ไม่ขอสิทธิ์ SysEx

MIDI ใช้เลขโน้ตจริงที่อุปกรณ์ส่งมา (0–127) เมนูช่วงเสียงในเว็บเปลี่ยนเฉพาะแป้นพิมพ์คอมพิวเตอร์และคีย์บนจอ ไม่ย้ายคีย์ MIDI กลองรับเลข 36, 38, 42, 46, 39, 45, 49, 51

Web MIDI ต้องได้รับอนุญาตและอยู่ใน secure context เช่น HTTPS หรือ localhost หากเบราว์เซอร์ภายในแอปจำกัด MIDI ให้เปิดไฟล์ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ หากยังถูกจำกัด ให้เสิร์ฟไฟล์ผ่าน localhost หรือ HTTPS ตามข้อความแจ้งของเบราว์เซอร์

อ้างอิง: [Web MIDI API](https://developer.mozilla.org/en-US/docs/Web/API/Web_MIDI_API), [ข้อกำหนด Web MIDI](https://www.w3.org/TR/webmidi/)

## ขอบเขต

ส่วนนี้เป็นการเล่นสด ยังไม่บันทึกโน้ตที่กดลง Piano Roll และไม่รวมการเล่นสดลง WAV ของโปรเจกต์ ไม่ใช่ระบบติดตั้งปลั๊กอิน VST/AU และไม่มี MIDI output ส่งเสียงไปยังเครื่องดนตรีภายนอก

ตรวจการกดแป้นพิมพ์ในเบราว์เซอร์ครบ 38 เครื่องดนตรี, เปลี่ยน octave, กลอง และปล่อยปุ่มแล้วจำนวนเสียงกลับ 0 โดยไม่พบข้อผิดพลาด JavaScript ตรวจตรรกะ MIDI ด้วยข้อความจำลองรวม Note On/Off, sustain, channel filtering, panic และ polyphony แล้ว **ยังไม่ได้ทดสอบกับอุปกรณ์ USB MIDI จริง**
