# Beat Studio Fantasy v1.5

เปิด Beat-Studio-Fantasy-v1.5.html ด้วยเบราว์เซอร์ ใช้งานออฟไลน์ได้ และมีเครื่องดนตรี 38 เสียงเหมือน v1.4

## 1. เลือกหลายโน้ตและจัดท่อน

Shift+คลิกเพื่อเพิ่มหรือลดโน้ตที่เลือก กด **เลือกทั้งหมด** เพื่อเลือกทั้งแทร็ก ลากกลางโน้ตที่เลือกเพื่อย้ายเป็นกลุ่ม หรือลากขอบขวาเพื่อปรับความยาวพร้อมกัน ปุ่ม **⬚ เลือก** ช่วยให้คลิกพื้นที่ว่างโดยไม่สร้างโน้ต

กด **คัดลอก** แล้วคลิกไม้บรรทัดเพื่อกำหนดตำแหน่งเส้นเล่น กด **วางที่เส้นเล่น** เพื่อวางกลุ่มโน้ต ทำซ้ำ, เลื่อนเสียงขึ้น/ลง, ปรับความแรง และ Delete ทำงานกับทั้งกลุ่ม กด Ctrl/Cmd+A, C, V, D ได้เมื่อไม่ได้พิมพ์ในช่องข้อความ

ใน **คัดลอกท่อน** ระบุห้องต้นทางและห้องปลายทาง เลือกทำเฉพาะแทร็กปัจจุบันหรือทุกแทร็ก เลือกชื่อ Intro/Main/Bridge/Outro โปรแกรมเพิ่มจำนวนห้องให้อัตโนมัติสูงสุด 16 ห้อง โน้ตจะถูกเพิ่มรวมกับสิ่งที่อยู่ปลายทาง ใช้ Undo หากต้องการย้อนกลับ

## 2. คีย์และคอร์ด

เลือกคีย์กับสเกล Major, Minor หรือ Major Pentatonic เพื่อไฮไลต์คีย์ใน Piano Roll เปิด **วางโน้ตเข้าคีย์** เพื่อให้โน้ตที่วาดใหม่ตรงสเกล โน้ตเดิมและการย้ายกลุ่มจะไม่ถูกเปลี่ยนคีย์อัตโนมัติ

เลือกขั้นคอร์ดและ Octave แล้วกด **วางคอร์ด** โปรแกรมวาง 3 เสียงจากสเกลที่ตำแหน่งเส้นเล่น ใช้ความยาวตามตัวเลือกใน Piano Roll กลองไม่มีปุ่มวางคอร์ด

## 3. Humanize

เลือกโน้ตก่อน ปรับช่วงเวลาคลาดเคลื่อน 0–30 ms และความแรง 0–25% แล้วกด **ปรับโน้ตที่เลือก** ค่าที่สุ่มถูกบันทึกในโปรเจกต์และใช้เหมือนกันทั้งเล่นสดและส่งออก กดซ้ำสุ่มใหม่จากค่าฐาน ไม่สะสมการเปลี่ยนแปลงไปเรื่อย ๆ

กด **คืนค่าเดิม** เพื่อคืนค่าก่อน Humanize ของโน้ตที่เลือก หรือใช้ Undo หากปรับความแรงโน้ตเองหลัง Humanize ค่าฐานความแรงเดิมจะถูกยกเลิก

## 4. ลูกเล่นตามเครื่องดนตรี

- พิณอีสาน: รูดเสียงขึ้น 2 ครึ่งเสียง หรือรัวสายเป็นโน้ตย่อย
- ฮาร์ปและเครื่องสายที่รองรับ: ไล่โน้ตในคอร์ดจากเสียงต่ำขึ้นสูง เมื่อโน้ตเริ่มพร้อมกัน
- คาลิมบา/เอ็มบีรา: สลับความแรงเบา–หนักตามลำดับโน้ตในแทร็ก

ลูกเล่นใช้กับแทร็กที่เลือกและบันทึกไปกับ JSON เสียงยังเป็นการสังเคราะห์ ไม่ใช่เทคนิคที่บันทึกจากเครื่องดนตรีจริง

## 5. WAV และ Loop WAV

**WAV** ส่งออกเพลงหนึ่งรอบพร้อมเผื่อหางเสียง ส่วน **Loop WAV** เรนเดอร์หลายรอบเพื่อสะสมหาง Reverb/Delay จากรอบก่อน แล้วเก็บหนึ่งรอบ ความยาวตรงจำนวนห้องที่ตั้งไว้ ปัดเป็นจำนวนเต็มของ sample ที่ 44,100 Hz ไม่มีช่วงเงียบ 7 วินาทีต่อท้าย

ไฟล์ทั้งสองเป็นสเตอริโอ 16-bit และใช้ Master, Mute/Solo, ลูกเล่น และค่า Humanize ปัจจุบัน เมโทรนอมไม่ถูกส่งออก นำ Loop WAV ไปตั้ง repeat ในโปรแกรมปลายทางเพื่อวนต่อกัน การเปลี่ยนคอร์ดหรือทำนองที่รอยต่อยังขึ้นกับโน้ตที่ผู้แต่งเลือก

## เก็บงานและเพลงตัวอย่าง

ส่งออก JSON ก่อนย้ายเครื่องหรือเบราว์เซอร์ รุ่นนี้อ่านไฟล์เดิมได้ และใช้พื้นที่บันทึกอัตโนมัติ v1.5 แยกจากรุ่นก่อน ลูกเล่นใหม่ควรเปิดด้วย v1.5 ขึ้นไป

นำเข้า **Adventure-Sketch-v1.5.json** เพื่อทดลองเพลง 8 ห้อง มี Intro/Main, ลูกเล่นพิณ/ฮาร์ป/คาลิมบา และค่า Humanize ที่กำหนดไว้
